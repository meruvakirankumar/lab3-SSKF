# Code Architecture Analyzer - Development Instructions

## Project Overview

**Code Architecture Analyzer** is a full-stack web application that enables developers to upload codebases (as ZIP files) and receive instant Mermaid diagram visualizations showing code structure, dependencies, and data flows. The system integrates AI analysis via OpenAI/OpenRouter APIs for enhanced insights.

**Stack:** React (TypeScript) + Python FastAPI + Couchbase + Polytope Framework

---

## Architecture & Components

### Frontend (React Web App)
- **Location:** `services/react-web-app/`
- **Technology:** React Router, TypeScript, TailwindCSS, Vite
- **Ports:** `51732` (dev) → API proxies to `3030`
- **Key Routes:**
  - `/` - Home/project upload interface
  - `/projects/{id}` - Architecture diagram viewer
  - `/maintenance-requests` - Maintenance view

### Backend (Python FastAPI)
- **Location:** `services/python-fast-api/`
- **Technology:** FastAPI, uvicorn, Python 3.13
- **Ports:** `3030`
- **Key Routes:**
  - `POST /api/upload` - Receive ZIP file + project name
  - `POST /api/projects/{id}/analyze` - Trigger code analysis
  - `GET /api/projects/{id}` - Get project metadata
  - `GET /api/projects/{id}/diagrams` - Fetch Mermaid diagrams
  - `GET /api/projects/{id}/dataflows` - Get detected data flows
  - `GET /api/projects/{id}/insights` - AI-generated insights

### Analysis Pipeline
1. **File Scanning** (`src/routes/base.py::_scan_codebase`)
   - Recursively scans uploaded ZIP content
   - Supports: `.py`, `.js`, `.jsx`, `.ts`, `.tsx`, `.java`, `.go`, `.rb`, `.php`, `.cs`, `.c`, `.cpp`
   - Max 250 files per scan (configurable)

2. **Import/Export Extraction** (`src/routes/base.py::_extract_imports`, `_extract_exports`)
   - Regex-based parsing of module dependencies
   - Lists exported classes, functions, constants per file

3. **Diagram Generation** (`src/routes/base.py::_store_analysis`)
   - **Component Diagram** - File structure and organization
   - **Class Diagram** - Exported symbols and relationships
   - **Dependency Diagram** - Import relationships
   - **Flowchart Diagram** - Data flow visualization
   - All output in Mermaid format

4. **AI Enhancement** (`src/routes/base.py::_get_openai_analysis`)
   - Calls OpenAI/OpenRouter API (detected by key prefix)
   - Provides architecture pattern, main components, tech stack analysis
   - Graceful fallback if API unavailable

### Data Persistence
- **Temporary:** Uploaded ZIPs in `/tmp/code_analyzer_uploads/`
- **In-Memory:** `PROJECTS_DB`, `DIAGRAMS_DB`, `DATAFLOWS_DB`, `INSIGHTS_DB` dicts
- **Future:** Couchbase (service available but not integrated yet)

## Configuration Files

### `config/openapi-key.env`
Contains API credentials for OpenAI/OpenRouter integration:
```env
OPENAPI_KEY=sk-or-v1-...  # OpenRouter or OpenAI API key
AZURE_OPENAI_DEPLOYMENT=gpt-5.4
AZURE_OPENAI_API_VERSION=2024-12-01-preview
```
- **Note:** Included in requests to OpenAI/OpenRouter
- **Key Detection:** Prefix `sk-or-` = OpenRouter; `sk-` = OpenAI

### `config/values.yml`
Runtime configuration (ports, hosts, credentials):
```yaml
python-fast-api-http-port: '3030'
react-web-app-port: '51732'
couchbase-server-host: couchbase
```

### `config/secrets.yml`
Sensitive data (passwords, API keys):
```yaml
couchbase-password: asdfasdf
couchbase-username: asdf
```

### `services/python-fast-api/polytope.yml`
Defines FastAPI service, mounts `/clients/python`, `/models/python`, `/config`

## Development Workflow

### Setup
```bash
# Initialize session (Polytope)
pt initialize-session

# Validate environment
python services/python-fast-api/bin/validate

# Or manually:
cd services/python-fast-api
uv sync  # Install dependencies (uses pyproject.toml)
```

### Running Services
```bash
# Terminal 1: Backend
cd services/python-fast-api
./bin/run  # Starts uvicorn on port 3030

# Terminal 2: Frontend
cd services/react-web-app
npm install
npm run dev  # Vite dev server on port 51732
```

### Testing Flow
1. Open `http://localhost:51732`
2. Enter project name (e.g., "My App")
3. Upload a ZIP file of code
4. Click "Upload & Analyze"
5. View generated Mermaid diagrams on results page

## Environment Variables

### FastAPI (`services/python-fast-api`)
Set in `config/values.yml` and mounted from `services/python-fast-api/polytope.yml`:
- `HTTP_PORT` - API server port (default: `3030`)
- `HTTP_AUTORELOAD` - Auto-reload on code changes (default: `true`)
- `HTTP_EXPOSE_ERRORS` - Dev mode error details (default: `true`)
- `LOG_LEVEL` - Logging verbosity (default: `INFO`)
- `COUCHBASE_SERVER_HOST` - Couchbase connection
- `COUCHBASE_SERVER_USERNAME` / `_PASSWORD`
- `ANALYZER_SCAN_MAX_FILES` - Max files to scan (default: `250`)
- `ANALYZER_OPENAI_MAX_FILES` - Max files for AI analysis (default: `120`)

## Common Patterns & Conventions

### Adding New Diagram Types
1. Create `_generate_{name}_diagram(files, ai_insights)` function in `src/routes/base.py`
2. Add to `diagrams` dict in `_store_analysis()`
3. React component automatically renders new type via Mermaid

### Extending File Type Support
Edit `SUPPORTED_EXTENSIONS` in `services/python-fast-api/src/routes/base.py`:
```python
SUPPORTED_EXTENSIONS = {
    ".py", ".js", ".jsx", ".ts", ".tsx",  # Current
    ".dart",  # Add new
}
```

### Adding OpenAI Integration Points
1. Call `_get_openai_analysis(files)` with file list
2. Returns dict with: `architecture_pattern`, `main_components`, `technologies`, etc.
3. Use AI insights in diagram generation for enhanced visualization

### Error Handling
- API errors return `{"success": false, "detail": "..."}` with HTTP status code
- Analysis failures set project `status = "failed"` with `error_message`
- AI analysis gracefully falls back if API unavailable

## Deployment Notes

- **Max Upload Size:** 2 GB (configurable via `MAX_UPLOAD_BYTES`)
- **Analysis Timeout:** Files scanned up to `SCAN_MAX_FILE_BYTES` (default: 200KB)
- **Storage:** Currently in-memory; migrate to Couchbase for production
- **CORS:** Enabled for all origins (frontend dev convenience)

## Troubleshooting

| Issue | Solution |
|-------|----------|
| `ModuleNotFoundError` on `utils` | Ensure working dir is `services/python-fast-api/` |
| Vite can't reach backend | Check `react-router.config.ts` proxy → `http://localhost:3030` |
| Mermaid diagrams not rendering | Check MermaidDiagram component error logs; verify Mermaid syntax |
| OpenAI API fails | Verify `OPENAPI_KEY` in `config/openapi-key.env`; check API rate limits |
| Couchbase not found | Not required yet; in-memory storage active |
